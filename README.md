# Titanic Survival Analysis

## Overview

This project analyzes the Titanic dataset using Python and Plotly to explore the factors that influenced passenger survival during the Titanic disaster.

The project focuses on data cleaning, preprocessing, feature engineering, and creating modern visualizations to identify patterns and insights related to survival rates.



## Project Objectives

* Analyze passenger survival patterns
* Identify the most influential survival factors
* Perform data cleaning and preprocessing
* Create interactive and visually appealing charts
* Generate meaningful business/data insights



## Dataset Information

The dataset contains passenger-level information such as:

* Passenger Class (Pclass)
* Gender (Sex)
* Age
* Fare
* Embarked Port
* Cabin Information
* Survival Status

Dataset used: Titanic Dataset



## Technologies Used

* Python
* Pandas
* NumPy
* Plotly
* Matplotlib
* Jupyter Notebook 
* PowerPoint



## Data Cleaning & Preparation

The following preprocessing steps were applied before analysis:

* Handling missing values
* Age imputation using median values
* Fare imputation
* Embarked value replacement using mode
* Feature engineering for:

  * Age Groups
  * Fare Quartiles
  * Cabin Availability
* Data validation and consistency checks



## Exploratory Data Analysis (EDA)

### 1. Survival by Gender

The analysis showed that females had a significantly higher survival rate than males.

### 2. Survival by Passenger Class

First-class passengers had the highest survival probability compared to second and third class passengers.

### 3. Survival by Fare

Passengers with higher ticket fares were more likely to survive.

### 4. Survival by Age Group

Children showed higher survival rates due to evacuation priorities.

### 5. Embarked Port Analysis

Passengers embarking from Cherbourg had higher average survival rates.

### 6. Cabin Availability Impact

Passengers with recorded cabin information generally had better survival outcomes.


## Key Insights

* Gender was one of the strongest predictors of survival.
* Passenger class strongly influenced survival chances.
* Higher fares were associated with increased survival rates.
* Children and females had evacuation priority.
* Socio-economic status played a major role in survival outcomes.



## Visualizations

The project includes:

* Bar Charts
* Survival Comparison Charts
* Fare Distribution Analysis
* Age Group Analysis
* Interactive Plotly Visualizations



## Final Conclusion

The analysis demonstrates that survival aboard the Titanic was heavily influenced by gender, passenger class, fare, and age.

Females, children, and first-class passengers had the highest survival probabilities, highlighting the impact of social and economic status during the disaster.
